# Костя & Ксюша — наша история

Интерактивный mobile-first сайт-подарок в формате полноэкранной презентации на React, TypeScript, Vite/Vinext, Tailwind CSS и Framer Motion.

## Как запустить

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который появится в терминале. Обычно это `http://localhost:3000`.

## Где менять историю

Весь личный контент находится в одном файле:

```text
src/data/story.ts
```

Там хранятся имена, даты, главы, подписи, цитаты, галерея, комплименты, песня, данные счётчика и финальное сообщение. Компоненты отвечают только за отображение.

## Пароль и навигация

Экран-пароль использует код из `story.access.code`. Сейчас это `12.05.2025`. После входа каждая глава занимает ровно один экран: переходить можно кнопками, клавишами ← → и свайпом. Вертикальная прокрутка отключена.

## Как менять даты

Основные машинные даты находятся в объекте `story.dates`. Используется ISO-формат с часовым поясом Екатеринбурга:

```ts
relationship: '2025-10-22T00:00:00+05:00';
```

Видимые подписи дат находятся рядом с соответствующими событиями. Счётчик автоматически берёт дату начала отношений из `story.dates.relationship`.

## Как добавлять события

Добавьте новый объект в массив `story.events`:

```ts
{
  id: 'unique-id',
  date: '1 ИЮНЯ 2026',
  title: 'Название сцены',
  text: ['Первый абзац.', 'Второй абзац.'],
  quote: 'Необязательная цитата',
  image: '/images/story/photo.jpg',
  imageAlt: 'Что изображено на фотографии',
  layout: 'editorial',
}
```

Доступные варианты `layout`: `map`, `editorial`, `fullscreen`, `letter`, `type`. Чтобы новая глава появилась на странице, подключите её по `id` в `components/story/story-experience.tsx` рядом с другими событиями.

## Как менять фотографии

Фотографии распределены по папкам:

```text
public/images/story/   — фотографии конкретных событий
public/images/gallery/ — обычные совместные фотографии
```

Скопируйте новый файл в нужную папку и измените путь в `src/data/story.ts`. Для мобильной версии лучше использовать JPG или WebP разумного размера. Вертикальные кадры показываются без опасного обрезания лиц; для каждого изображения обязательно заполните понятный `alt`.

Исходная папка `../материалы` проектом не изменяется.

## Как заменить фоновые видео

Положите ролик по адресу:

```text
public/videos/daivinchik.mp4
public/videos/her-birthday.mp4
```

Или измените `story.intro.video` и `video` нужного события в data-файле. Видео работают как беззвучный фон и автоматически зацикливаются.

## Как изменить ссылку на карту

Ссылка хранится в поле `mapUrl` события `first-meeting`. Сейчас нажатие открывает отмеченное место во внешнем приложении карт.

## Как заменить музыку

Основной аудиофайл находится в `public/music/`. Путь задаётся в `story.soundtrack`:

```ts
intro: {
  file: '/music/track-1.mp3';
}
```

Композиция плавно запускается сразу после правильного ввода даты и играет на протяжении всей истории без переключений. В углу доступны пауза и выключение звука.

## Как изменить финальное сообщение

Отредактируйте `story.final.paragraphs`, `signature` и `author`. Лучше сохранять обычный стиль речи Кости и не превращать текст в формальное поздравление.

## Проверка и production-сборка

```bash
npm run lint
npx tsc --noEmit
npm run build
```

Результат production-сборки создаётся в папке `dist`.

## Как разместить в интернете

Проект подготовлен для OpenAI Sites и Cloudflare Workers.

- В Codex сайт можно опубликовать через Sites после успешной сборки.
- Для самостоятельного Cloudflare-деплоя сначала выполните `npm run build`, затем используйте конфигурацию `dist/server/wrangler.json`.
- Перед отправкой ссылки проверьте, что на публичной версии допустимо показывать карту, личные фотографии и письмо.

Музыкальные файлы и фотографии должны использоваться с разрешения их владельцев.
